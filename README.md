# 🎰 せんだい散歩ガチャ
今日は、AIに散歩を決めてもらおう。

仙台市内のお散歩スポットを、ガチャ・おみくじ・AIを使ってランダムに提案する散歩支援アプリです。

「今日はどこに行こう？」と迷ったときに、AIがあなたに合った散歩先を提案します。

## 📱 コンセプト
「せっかくの休日だけど、どこに行こうか決まらない」

そんなときに、検索して探すのではなく、

ガチャを引いて、偶然の散歩を楽しむ。

という体験を提供します。

単純な完全ランダムではなく、

今日の気分
散歩時間
エリア
過去に訪れた場所
お気に入り
スポットの特徴
などを考慮し、AIによって「自分にちょうどいいランダム」を作ります。

## 🤖 AIおすすめ
ユーザーの条件や過去の訪問履歴などを考慮し、登録されているスポットからおすすめを選択します。

AIにスポットそのものを生成させるのではなく、信頼できるスポットデータを候補としてAIに渡す設計を採用します。

🗺️ スポット情報

❤️ お気に入り
気になったスポットをお気に入りに登録できます。

🚶 訪問履歴
実際に訪れたスポットを記録できます。

過去に訪問した場所をガチャの候補から除外するなど、AIによるおすすめにも利用します。

## 🎰 ガチャの仕組み
ガチャは完全なランダムではなく、以下の流れで候補を決定します。

登録済みスポット
       │
       ▼
ユーザー条件で絞り込み
       │
       ▼
訪問済みスポットを考慮
       │
       ▼
AIによる候補選定
       │
       ▼
   今日の散歩先

例
ユーザー条件

・一人
・60分
・自然が好き
・まだ行ったことがない場所
・青葉区

        ↓

AI

「西公園は訪問済み。
今日は青葉山をおすすめします。」

        ↓

🎉 今日の散歩先

青葉山
